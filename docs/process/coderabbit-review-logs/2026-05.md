## 2026-05-09 PR #152 Phase 10 vbac extract/combine safety

- 指摘

  - `isPathInside` が raw path の `path.relative` だけで判定しており、symlink / junction 越しの escape を検知できない。

  - text component は改行差分を正規化し、binary component は byte 比較する内容検証を追加した。
  - `packages/extension/test/suite/index.ts` に content mismatch の最小回帰を追加した。
- 検証
